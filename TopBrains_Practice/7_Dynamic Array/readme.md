Dynamic Array (HackerRank)
Problem Statement

You are given n empty sequences (dynamic arrays), numbered from 0 to n - 1.

Initially:

Each sequence is empty.
lastAnswer = 0.

You need to process two types of queries.

Query Type 1
1 x y
Compute:
index = (x XOR lastAnswer) % n
Append y to the sequence at index.
Query Type 2
2 x y
Compute:
index = (x XOR lastAnswer) % n
Set:
lastAnswer = sequence[index][ y % sequence[index].Count ]
Store lastAnswer in the result list.

After processing all queries, return the list containing all values of lastAnswer generated by Type 2 queries.

Function Description

Complete the function:

dynamicArray(int n, List<List<int>> queries)
Parameters
n → Number of empty sequences.
queries → List of queries.
Returns
A list of integers representing all lastAnswer values.
Input Format
First line contains two integers:
n q

where:

n = number of sequences
q = number of queries

Each of the next q lines contains one query.

Sample Input
2 5
1 0 5
1 1 7
1 0 3
2 1 0
2 1 1
Expected Output
7
3
Explanation

Initially

Sequence 0 : [ ]
Sequence 1 : [ ]

lastAnswer = 0
Query 1
1 0 5
index = (0 XOR 0) % 2 = 0

Append 5

Sequence0 = [5]
Sequence1 = [ ]
Query 2
1 1 7
index = (1 XOR 0) % 2 = 1

Append 7

Sequence0 = [5]
Sequence1 = [7]
Query 3
1 0 3

Append 3

Sequence0 = [5,3]
Sequence1 = [7]
Query 4
2 1 0
index = (1 XOR 0)%2 = 1

lastAnswer =
Sequence1[0 % 1]

= 7

Output

7
Query 5
2 1 1
index=(1 XOR 7)%2

=0

lastAnswer =
Sequence0[1 % 2]

=3

Output

3

Result

[7,3]
