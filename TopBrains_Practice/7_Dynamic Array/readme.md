# 📚 Dynamic Array (HackerRank)

A C# implementation of the **Dynamic Array** problem from HackerRank. This project demonstrates how to manage multiple dynamic sequences efficiently while processing queries using the **XOR (`^`) operation** and the **lastAnswer** variable.

> **Data Structure:** Dynamic Arrays (List of Lists)  
> **Technique Used:** XOR-Based Indexing & Query Processing

---

## 🎯 Problem Statement

You are given **n** empty sequences (dynamic arrays), numbered from **0** to **n - 1**.

Initially:

- Every sequence is empty.
- `lastAnswer = 0`

You must process two types of queries that update the sequences or retrieve values from them.

Complete the following function:

```csharp
dynamicArray(int n, List<List<int>> queries)
```

---

## 📥 Input Format

The first line contains two integers:

```text
n q
```

Where:

- **n** = Number of sequences
- **q** = Number of queries

Each of the next **q** lines contains one query.

---

## 📋 Query Types

### 🔹 Type 1 Query

```text
1 x y
```

Calculate:

```text
index = (x XOR lastAnswer) % n
```

Append **y** to the sequence at the calculated index.

---

### 🔹 Type 2 Query

```text
2 x y
```

Calculate:

```text
index = (x XOR lastAnswer) % n
```

Then update:

```text
lastAnswer = sequence[index][ y % sequence[index].Count ]
```

Store the new **lastAnswer** in the result list.

---

## 📤 Output Format

Return a list containing all values of **lastAnswer** generated by **Type 2** queries.

---

## ✅ Sample Input

```text
2 5
1 0 5
1 1 7
1 0 3
2 1 0
2 1 1
```

### Sample Output

```text
7
3
```

---

## 📌 Explanation

### Initial State

```text
Sequence 0 : [ ]
Sequence 1 : [ ]

lastAnswer = 0
```

---

### Query 1

```text
1 0 5
```

```text
index = (0 XOR 0) % 2 = 0
```

Append **5**

```text
Sequence 0 : [5]
Sequence 1 : [ ]
```

---

### Query 2

```text
1 1 7
```

```text
index = (1 XOR 0) % 2 = 1
```

Append **7**

```text
Sequence 0 : [5]
Sequence 1 : [7]
```

---

### Query 3

```text
1 0 3
```

Append **3**

```text
Sequence 0 : [5, 3]
Sequence 1 : [7]
```

---

### Query 4

```text
2 1 0
```

```text
index = (1 XOR 0) % 2 = 1
```

```text
lastAnswer = Sequence1[0 % 1]
            = 7
```

**Output**

```text
7
```

---

### Query 5

```text
2 1 1
```

```text
index = (1 XOR 7) % 2 = 0
```

```text
lastAnswer = Sequence0[1 % 2]
            = 3
```

**Output**

```text
3
```

---

## 📊 Result

```text
[7, 3]
```

---

# ⚙️ Algorithm

1. Create **n** empty dynamic arrays.
2. Initialize `lastAnswer = 0`.
3. Process each query:
   - **Type 1:** Compute the index and append the value.
   - **Type 2:** Compute the index, update `lastAnswer`, and store it in the result.
4. Return the list of all `lastAnswer` values.

# ⏱️ Complexity Analysis

| Operation | Complexity |
|-----------|-----------:|
| Time Complexity | **O(q)** |
| Space Complexity | **O(n + q)** |

Where:

- **n** = Number of sequences
- **q** = Number of queries

Each query is processed once, resulting in linear time complexity.
